Understanding the Test Case Columns

Use this reference to understand the information displayed in each generated test case.

ID

A unique test case reference number, such as TC-001, used for tracking, reporting, and discussion.

Field

The form field, requirement, ticket, or functional item from the uploaded IRD that is being tested.

Priority

The importance of executing the test case. High-priority cases normally cover mandatory fields, key validations, and critical business rules.

Scenario

A short description of the behavior or condition being verified by the test case.

Steps

The ordered actions a tester should perform to execute the test case consistently.

Test data

The value, file, selection, or input condition that should be used while performing the test.

Expected result

The correct system response that should occur after the steps are completed with the specified test data.

Please verify existing fields from your end to avoid any issues.
